Active Collection Rail

  • Node identity derives from hardware hostname + persistent UUID4 (.node_id).
  • Background heartbeat thread maintains ONLINE presence in central registry.
  • Continuous sampling of CPU, RAM, Disk, Load 1/5/15m, and host uptime.

Waits & Recoverable Failures

  • Initial registration uses exponential backoff doubling from 2s up to 60s.
  • Individual failed telemetry ticks are queued without crashing the agent.
  • After 3 consecutive failures, transparent re-registration triggers automatically.

Explicit Terminal Endings

  • KeyboardInterrupt (Ctrl+C) initiates clean shutdown and stops the thread.
  • Never hides an ending: fatal exceptions exit directly to terminal failure state.
