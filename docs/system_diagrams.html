Distributed Multi-Laptop Design

  • Central Server and Dashboard run on Host Laptop.
  • Node Agent runs on Worker Laptop streaming live telemetry.
  • Communicates over Wi-Fi/LAN via standard HTTP REST payloads.

Dual Trained ML Cores

  • Security: UNSW-NB15 Network Intrusion Dataset (51 features).
  • Maintenance: Alibaba Cloud Cluster Trace 2017 (11 features).
  • Isolation Forest runs unsupervised real-time anomaly detection.

Closed-Loop Intelligence

  • Fused multi-hazard risk engine (Security Risk + Failure Risk).
  • Intelligent Prevention Engine generates automated actionable runbooks.
  • KS-Test evaluates continuous statistical feature distribution drift.

Zero Dummy Data Guarantee

  • Dashboard queries database dynamically; zero hardcoded node lists.
  • Predictive Maintenance only runs when a real node is active and ONLINE.
  • Shows honest empty state when 0 node agents are connected.

End-to-End Real Telemetry

  • Real hardware counters flow directly from host OS into model inference.
  • Probabilities derived from trained model `predict_proba()`, not heuristics.
  • Failure risk and security risk combined mathematically with configurable weights.

Feature Engineering Alignment

  • Predictive Maintenance model inputs match actual Node Agent metrics.
  • Derived metric `Resource_pressure = (CPU * RAM) / 100` matches Alibaba training schema.
  • Zero data leakage: preprocessor fit strictly on training splits.

Statistical Data Drift (KS-Test)

  • Continuous evaluation of feature empirical cumulative distribution functions (ECDF).
  • Flags feature drift when Kolmogorov-Smirnov $p < 0.05$.
  • Candidate retraining executed with automated validation gate before deployment.

Self-Healing Connection

  • Exponential backoff on unreachable server prevents network floods.
  • Automatic transparent re-registration if Central Server restarts.
  • Independent heartbeat thread decouples liveness tracking from metric ingestion.

Graceful Termination

  • Ctrl+C gracefully stops background threads and cleans up sockets.
  • Terminal failure exits are never hidden or swallowed.
